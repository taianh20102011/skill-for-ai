## 🚀 Installation 1-Clic & Maillage Multi-Agents

Exécutez une seule commande dans votre terminal :

```bash
npx skill-for-ai
```
*(Ou directement depuis GitHub : `npx github:taianh20102011/skill-for-ai`)*

Cette commande installe automatiquement **plus de 90 compétences de niveau production** sur vos environnements d'agents :
* 🔹 **Google Antigravity / Gemini CLI** : `~/.gemini/config/skills`
* 🔹 **Claude Code** : `~/.claude/skills`
* 🔹 **OpenCode / Codex Agents** : `~/.agents/skills`
* 🔹 **Cursor / VS Code** : Génère automatiquement `AGENTS.md` et `.cursorrules` à la racine de votre projet.

---

### 🤖 Demande de Permission & Sélection Interactive du Mode
Lors de l'installation, le CLI vous demandera confirmation :
1. **Confirmation du Maillage Unifié Multi-Agents** :
   ```text
   ? Autorisez-vous la connexion automatique de tous les agents IA en un système unifié ? (Y/n)
   ```
2. **Choix du Mode de Fonctionnement** :
   * 🌟 **Senior Dev Mode (Recommandé)** :
     * Applique la philosophie **YAGNI (Ponytail)** : Code minimal et précis pour résoudre le problème, sans surcharge ni abstractions inutiles.
     * Boucle de compilation autonome (`pnpm build`, `./gradlew build`, `cargo check`), capture les traces d'erreurs et auto-corrige le code source.
     * Audits de sécurité automatisés basés sur les directives Cloudflare et l'OWASP Top 10.
   * 🎓 **Junior Dev Mode** :
     * Mode tutoriel et accompagnement : Explications pas-à-pas et détaillées de chaque fonction et variable.
     * Ajoute des commentaires explicatifs pour faciliter l'apprentissage.

## 🛠️ Super-Commande Autonome : `/xaydung`

Une fois installé, lancez la génération et le développement autonome directement dans **Antigravity / Claude Code / Cursor** :

```text
/xaydung web <spécifications du projet web>
/xaydung app <description de l'application desktop ou mobile>
/xaydung plugin <fonctionnalités du plugin minecraft paper/purpur>
/xaydung tool <utilitaire CLI ou script d'automatisation>
```

### Pipeline Autonome en Arrière-plan :
1. **Analyse Architecturale & Brainstorming** : Établissement des spécifications techniques et découpage des tâches.
2. **Initialisation du Scaffold** : Sélection de la stack optimale (React/Tailwind/GSAP/Lenis, Tauri v2 / Rust, ou Paper Adventure).
3. **Implémentation Autonome** : Rédaction d'un code propre respectant strictement le mode sélectionné (Senior ou Junior).
4. **Boucle d'Auto-Correction (Compiler Loop)** : Exécute les commandes de build/test, analyse les journaux d'erreurs et corrige les bogues.
5. **Audit de Sécurité & Qualité** : Contrôle automatique via les guides Cloudflare, l'OWASP Top 10 et Semgrep SAST.

## 📦 Catalogue des Compétences (90+ Compétences Intégrées)

### 1. Web UI Haut de Gamme & Micro-Interactions (Zero Slop)
* **`anti-slop-web-ui`** : Règles d'esthétique soignée : Dark mode `#080808`, typographie Geist / JetBrains Mono, physique dynamique 150-250ms.
* **`react-bits`** : Composants animés : *SplitText, DecryptedText, Iridescence, Aurora, Particles, SpotlightCard*.
* **`animate-ui`** : Micro-interactions fluides style Apple/Linear : morphing de modales, onglets fluides, amortissements par ressorts.
* **`cinematic-3d-web`** : Rendu 3D Canvas avec R3F, Drei, Three.js et shaders GLSL optimisés à 60 FPS.
* **`gsap-scroll-mastery`** : GSAP ScrollTrigger synchronisé avec le défilement fluide Lenis.
* **`vercel-react-performance`** : Optimisation des Core Web Vitals (LCP < 2s, INP < 150ms, CLS < 0.05).

### 2. Automatisation Web & Mobile (Agents Navigateur & Mobile)
* **`browser-use-agent`** : Navigation web autonome, saisie de formulaires et extraction DOM avec Playwright.
* **`mobile-app-automation-agent`** : Contrôle et tests automatisés d'UI Mobile (Android UIAutomator2, iOS XCUITest, Appium, LaVague LAM).

### 3. Architecture Minecraft Propre & Bac à Sable IA
* **Suite de 13 Compétences Minecraft** : `minecraft-plugin-dev`, `minecraft-modding`, `minecraft-commands-scripting`, `minecraft-datapack`, `minecraft-server-admin`, `minecraft-worldedit-ops`, etc.
* **Intégration Bac à Sable IA** : Connexion avec `AgentCraft` (bureau virtuel pour agents de code) et `MindCraft` (bot Mineflayer).

### 4. Cybersécurité d'Entreprise & Ingénierie Défensive
* **`cloudflare-security-audit`** : Audit de sécurité complet selon les standards de Cloudflare.
* **`owasp-top-10-audit` & `owasp-security-cheatsheets`** : Détection et listes de contrôle proactives contre les vulnérabilités OWASP Top 10.
* **`siem-detection-and-blue-team`** : Écriture de règles de détection Sigma YAML et sécurisation d'Active Directory.
* **`secret-leak-detection`** : Détection préalable aux commits des fuites de clés API (OpenAI, AWS, GitHub).
* **`reverse-engineer-anything` (REA)** : Rétro-ingénierie binaire, analyse de fichiers APK, Electron et WebAssembly.

### 5. Boucles de Développement Autonomes & Outillage
* **`superpowers`** : Brainstorming, planification structurée (`writing-plans`), développement piloté par sous-agents, TDD et vérification avant complétion.
* **`ponytail`** : Mode Développeur Senior Pragmatique (YAGNI, suppression du code mort, suivi de la dette technique).
* **`agent-skills-addy`** : Bonnes pratiques d'ingénierie web par le responsable de Google Chrome (Addy Osmani).
