## 4. Open-Source GitHub Curations

Clone these repositories directly into your local workspace for immediate asset packs and starter systems:
- **`KenneyNL`** (`github.com/KenneyNL`): Official GitHub repositories for Kenney assets.
- **`Calinou/awesome-godot`**: Exhaustive list of Godot 4.x plugins, shaders, state machines, inventory systems, and templates.
- **`ellisonleao/magictools`**: Curated directory of game development software, engines, map editors (Tiled, LDtk), and shader tools.

## 5. Licensing Matrix & Compliance Invariants

| License | Commercial Use? | Attribution Required? | Can Modify? | Caveat |
| :--- | :--- | :--- | :--- | :--- |
| **CC0 (Public Domain)** | ✅ **YES** | ❌ NO (Recommended) | ✅ YES | Safest license for commercial indie games |
| **CC-BY** | ✅ **YES** | ✅ **YES (Mandatory)** | ✅ YES | Must include author name in game Credits screen |
| **CC-BY-SA** | ✅ **YES** | ✅ **YES** | ✅ YES | Derivative works must share same license |
| **Non-Commercial (NC)** | ❌ **NO** | ✅ **YES** | ✅ YES | Strictly for learning; cannot monetize or sell game |
