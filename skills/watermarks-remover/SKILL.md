# Watermarks Remover (AI Provenance & Metadata Sanitizer)

This skill encodes the inspection and sanitization pipeline inspired by Guillaume Meyer (`guillaumemeyer/watermarks-remover`) for stripping AI provenance watermarks, hidden Unicode characters, zero-width tracking spaces, and document metadata from files you own.

---

## 1. Supported Formats & Sanitization Targets

| Target Format | Common Watermark / Tracking Vectors | Sanitization Strategy |
| :--- | :--- | :--- |
| **Source Code & Markdown** | Zero-width spaces (`\u200B`, `\u200C`, `\u200D`), Unicode variation selectors (`\uFE00`–`\uFE0F`), comment provenance markers (`Generated by ...`) | Regex-based Unicode normalization and comment strip |
| **PNG & JPEG Images** | EXIF, XMP, IPTC provenance tags, SynthID-class metadata blocks | Strip ancillary chunks via ExifTool / Pillow, preserve raw pixel payload |
| **PDF & DOCX** | Creator metadata, Producer headers, revision timestamps, embedded tracking streams | PDF metadata wipe, DOCX `core.xml` & `app.xml` sanitization |
| **SVG** | Metadata blocks, creator comments, editor IDs | XML tree pruning, attribute stripping |

## 2. Text & Code Sanitization Engine (Python)

```python
import re

def remove_ai_text_watermarks(content: str) -> str:
    # 1. Strip Zero-Width and Hidden Unicode variation selectors
    # \u200B (Zero-width space), \u200C (ZWNJ), \u200D (ZWJ), \uFEFF (BOM), \uFE00-\uFE0F (Variation Selectors)
    hidden_unicode_pattern = re.compile(r'[\u200B\u200C\u200D\u200E\u200F\uFEFF\uFE00-\uFE0F\u2060-\u206F]')
    sanitized = hidden_unicode_pattern.sub('', content)

    # 2. Strip common AI generated header & footer comments
    ai_comments = [
        re.compile(r'^\s*//\s*(Generated by|Co-authored by|Created with)\s+.*$', re.MULTILINE | re.IGNORECASE),
        re.compile(r'^\s*#\s*(Generated by|Co-authored by|Created with)\s+.*$', re.MULTILINE | re.IGNORECASE),
        re.compile(r'^\s*<!--\s*(Generated by|Prompt:).*?-->\s*$', re.MULTILINE | re.IGNORECASE),
    ]
    for pattern in ai_comments:
        sanitized = pattern.sub('', sanitized)

    # 3. Normalize trailing whitespace and newlines
    sanitized = re.sub(r'[ \t]+$', '', sanitized, flags=re.MULTILINE)
    return sanitized.strip() + '\n'
```

## 3. Image Metadata Sanitization (Pillow / Python)

```python
from PIL import Image

def strip_image_metadata(input_path: str, output_path: str):
    with Image.open(input_path) as img:
        # Create a new image using only pixel data, discarding EXIF and XMP
        clean_img = Image.new(img.mode, img.size)
        clean_img.putdata(list(img.getdata()))
        clean_img.save(output_path, quality=95, optimize=True)
```

## 4. PDF & Document Provenance Wipe

When handling PDF files, strip the `/Producer`, `/Creator`, and `/CreationDate` dictionary keys to ensure zero document tracking:

```bash
# Via ExifTool
exiftool -all= -overwrite_original document.pdf
```
