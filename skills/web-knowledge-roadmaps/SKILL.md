# Web Engineering Roadmaps & Reference Skill

This skill anchors software design and learning progressions against established industry roadmaps, Mozilla MDN documentation, and free public APIs.

## 1. Engineering Roadmaps Hierarchy
- **Frontend Core**: Semantic HTML5, CSS Subgrid / Container Queries, TypeScript strict mode, Web Components, React Server Components.
- **Backend & Systems**: REST vs gRPC vs GraphQL, PostgreSQL ACID indexing, Redis caching layers, OAuth 2.0 / OIDC.
- **DevOps & Cloud**: Docker multi-stage builds, CI/CD automated lint/test matrices, Reverse proxies (Caddy, Nginx), Edge functions.

## 2. API Integration Standards
- Reference free public APIs from local index `D:\SKILL_AI\08-web-roadmaps-and-docs\public-apis` for mocking or live integrations.
- Always implement request timeout handlers (AbortController in fetch), typed DTO validation (Zod / Pydantic), and structured error envelopes.
