# Lệnh /xaydung - Autonomous Builder Skill

Use this skill whenever the user triggers `/xaydung` or requests complete autonomous building of web apps, mobile/desktop applications, Minecraft plugins, or developer tools.

## Supported Modes:
- `/xaydung web <description>`: React/Next.js + Tailwind + GSAP + Lenis + shadcn/ui + React Bits.
- `/xaydung app <description>`: Tauri v2 (Desktop) or Flutter/React Native (Mobile).
- `/xaydung plugin <description>`: Clean Paper Minecraft Plugin (Adventure, Triumph-GUI, Lamp, Lucko helper).
- `/xaydung tool <description>`: High-performance CLI / Desktop utility with self-healing tests.

## Autonomous Workflow:
1. Initialize project scaffold matching Anti-Slop specs.
2. Execute code generation following YAGNI Senior Dev standards.
3. Automatically run compiler loop, capture error stack traces, and patch issues iteratively.
4. Run OWASP and Cloudflare security audit checks.
5. Provide a 1-click startup command to the user.
