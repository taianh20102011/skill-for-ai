## 🚀 Cài Đặt 1-Click & Liên Kết Hệ Thống Đa Agent

Chỉ cần chạy duy nhất một lệnh trong Terminal:

```bash
npx skill-for-ai
```
*(Hoặc chạy tự động bỏ qua xác nhận: `npx skill-for-ai -y`)*

Lệnh trên sẽ tự động cài đặt và liên kết toàn bộ **320+ Kỹ Năng** vào môi trường làm việc của bạn:
* 🔹 **Google Antigravity / Gemini CLI**: `~/.gemini/config/skills`
* 🔹 **Claude Code**: `~/.claude/skills`
* 🔹 **OpenCode / Codex Agents**: `~/.agents/skills`
* 🔹 **Cursor / VS Code**: Tự động sinh `AGENTS.md` và `.cursorrules` ngay tại thư mục dự án hiện tại.

## 🛠️ Siêu Lệnh Tự Hành Khởi Tạo Dự Án: `/xaydung`

`skill-for-ai` tích hợp sẵn bộ khung tự động khởi tạo dự án. Bạn có thể gọi trực tiếp trong **Terminal** hoặc **gõ ngay trong khung chat của Antigravity, Claude Code, Cursor**:

```text
/xaydung web <mô tả dự án web>
/xaydung app <mô tả ứng dụng desktop hoặc mobile>
/xaydung plugin <tính năng plugin minecraft paper/purpur>
/xaydung tool <công cụ CLI hoặc script tự động hóa>
```

### Hoặc chạy trực tiếp từ Terminal:
```bash
xaydung web "SaaS Landing page dark mode với GSAP ScrollTrigger và Lenis"
xaydung app "Ứng dụng ghi chú markdown cho desktop bằng Tauri v2"
xaydung plugin "Plugin đồng bộ kinh tế đa server dùng Adventure MiniMessage"
xaydung tool "Công cụ CLI phân tích log tốc độ cao có kèm unit test"
```

### 🏗️ Các Kiến Trúc Tự Động Hóa Hỗ Trợ:
1. **`web`**: React 19 + Tailwind CSS + GSAP 25+ + Lenis Smooth Scroll + Animate UI (Chuẩn Anti-Slop `#080808`, font Geist / Plus Jakarta Sans).
2. **`app`**: Desktop App siêu nhẹ (Tauri v2 + Rust) hoặc Ứng dụng di động (Flutter).
3. **`plugin`**: Minecraft Paper/Purpur Plugin chuẩn doanh nghiệp (Adventure Kyori MiniMessage, Lamp command framework, Triumph-GUI).
4. **`tool`**: Công cụ CLI chuẩn production, tích hợp sẵn vòng lặp tự biên dịch và tự sửa lỗi khi có exception.

## 🌐 Trung Tâm Điều Khiển Web Dashboard (1-Chạm Là Xong)

Nếu bạn thích giao diện trực quan, hãy khởi chạy bảng điều khiển web:

```bash
# Khởi chạy từ terminal
skill-for-ai ui
# Hoặc dùng lệnh ngắn gọn
xaydung ui
```
*(Bảng điều khiển chạy cục bộ tại `http://localhost:3333`, hoàn toàn không cần cài thêm thư viện phụ thuộc)*

### 🎮 Các Tính Năng Trên Web Dashboard:
* ⚡ **Khởi Tạo Dự Án 1-Chạm (`/xaydung`)**: Chọn Web, Desktop App, Minecraft Plugin hoặc CLI Tool, nhập mô tả và bấm nút để AI dựng toàn bộ mã nguồn.
* 🎛️ **Chuyển Đổi Chế Độ Làm Việc**:
  * **Senior Dev Mode**: YAGNI (Ponytail), tối giản code, tự biên dịch và tự fix lỗi stack trace, kiểm toán bảo mật tự động.
  * **Junior Dev Mode**: Chế độ trợ giảng, giải thích chi tiết code và thêm comments dễ hiểu.
* 📊 **Đồ Họa & Tài Liệu**: 1-chạm tạo sơ đồ kiến trúc hệ thống, xuất Slide thuyết trình sang PowerPoint (`.pptx`), cào link web sang Markdown sạch.
* 🛡️ **Kiểm Toán Bảo Mật OWASP & Cloudflare**: Quét toàn bộ codebase tìm lỗ hổng bảo mật và lộ bí mật API key.
* 🤖 **Giám Sát Trạng Thái Đa Agent**: Xem trạng thái kết nối trực tiếp của Antigravity, Claude Code, Cursor và Codex.

## 📦 Danh Mục Kỹ Năng Đóng Gói (320 Kỹ Năng)

Hệ sinh thái gồm 320 kỹ năng chuẩn hóa thuộc 36 nhóm năng lực:

### 1. Giao Diện Web Cao Cấp & Vi Tương Tác (Anti-Slop)
* **`anti-slop-web-ui`**: Quy chuẩn thẩm mỹ cao cấp: Dark mode `#080808`, typography Geist / JetBrains Mono, spring physics 150-250ms.
* **`react-bits`**: Thư viện hiệu ứng UI động: *SplitText, DecryptedText, Iridescence, Aurora, Particles, SpotlightCard*.
* **`animate-ui`**: Vi tương tác đẳng cấp Apple/Linear: dialog morphing, smooth tabs, spring physics.
* **`cinematic-3d-web`**: 3D Canvas với R3F, Drei, Three.js, custom GLSL shaders tối ưu hóa 60 FPS.
* **`gsap-scroll-mastery`**: GSAP ScrollTrigger đồng bộ cùng Lenis Smooth Scroll.
* **`vercel-react-performance`**: Tối ưu Core Web Vitals (LCP < 2s, INP < 150ms, CLS < 0.05).

### 2. Tự Động Hóa Web & Mobile (Browser & Mobile Agents)
* **`browser-use-agent`**: Biến LLM thành Web Agent tự động điều hướng, điền form, cào dữ liệu qua Playwright.
* **`mobile-app-automation-agent`**: Điều khiển và kiểm thử tự động UI Mobile (Android UIAutomator2, iOS XCUITest, Appium, LaVague LAM).

### 3. Kiến Trúc Sạch Minecraft & AI Sandbox
* **Bộ 13 Kỹ Năng Minecraft**: `minecraft-plugin-dev`, `minecraft-modding`, `minecraft-commands-scripting`, `minecraft-datapack`, `minecraft-server-admin`, `minecraft-worldedit-ops`, `minecraft-ci-release`, v.v.

### 4. An Toàn Thông Tin Doanh Nghiệp & Phòng Thủ
* **`cloudflare-security-audit`**: Quy chuẩn kiểm toán bảo mật toàn diện theo chuẩn Cloudflare.
* **`owasp-top-10-audit` & `owasp-security-cheatsheets`**: Kiểm tra và phòng chống 10 lỗ hổng nghiêm trọng theo chuẩn OWASP.
* **`siem-detection-and-blue-team`**: Viết luật phát hiện tấn công theo chuẩn Sigma YAML; phòng thủ Active Directory.
* **`secret-leak-detection`**: Quét chặn rò rỉ API Keys (OpenAI, AWS, GitHub) trước khi commit.
* **`reverse-engineer-anything` (REA)**: Dịch ngược nhị phân, kiểm tra APK, Electron, WebAssembly.

### 5. Vòng Lặp Lập Trình Tự Hành & Công Cụ Kỹ Sư
* **`superpowers`**: Brainstorming, lập kế hoạch (`writing-plans`), subagent-driven development, TDD, và verification-before-completion.
* **`ponytail`**: Chế độ Senior Dev tối giản (YAGNI, triệt tiêu code rác, kiểm soát nợ kỹ thuật).
* **`local-ai-engine`**: Chạy agent offline 100% không tốn phí token qua Ollama, LM Studio, DeepSeek R1 / Qwen 2.5 Coder.
* **`autonomous-execution-loop`**: Vòng lặp code tự hành, tự biên dịch, tự bắt stack trace và tự vá mã nguồn.
