## 🚀 Cài Đặt 1-Click & Liên Kết Hệ Thống Đa Agent

Chỉ cần chạy duy nhất một lệnh trong Terminal:

```bash
npx skill-for-ai
```
*(Hoặc chạy tự động bỏ qua xác nhận: `npx skill-for-ai -y`)*

Lệnh trên sẽ tự động cài đặt và liên kết toàn bộ **337+ Kỹ Năng** vào môi trường làm việc của bạn:
* 🔹 **Google Antigravity / Gemini CLI**: `~/.gemini/config/skills`
* 🔹 **Claude Code**: `~/.claude/skills`
* 🔹 **OpenCode / Codex Agents**: `~/.agents/skills`
* 🔹 **Cursor / VS Code**: Tự động sinh `AGENTS.md` và `.cursorrules` ngay tại thư mục dự án hiện tại.

## 🛠️ Siêu Lệnh Tự Hành: `/xaydung` & `/unslop`

### 1. Khởi Tạo Dự Án Siêu Tốc (`/xaydung`)
Gõ ngay trong khung chat của **Antigravity, Claude Code, Cursor**:

```text
/xaydung web <mô tả dự án web>
/xaydung app <mô tả ứng dụng desktop hoặc mobile>
/xaydung game <mô tả tựa game / gameplay>
/xaydung video <mô tả kịch bản video / đồ họa toán học>
/xaydung plugin <tính năng plugin minecraft paper/purpur>
/xaydung tool <công cụ CLI hoặc script tự động hóa>
```

### 2. Khử Rác Giao Diện AI (`/unslop`)
Kiểm toán và thiết kế lại giao diện AI cẩu thả thành sản phẩm chỉn chu có chiều sâu:

```bash
# Trong Terminal
npx skill-for-ai unslop <file|dir> [--fix]
# hoặc
unslop <file|dir> [--fix]

# Trong AI Chat
/unslop [tệp tin | đường dẫn URL | component]
```
Kích hoạt chu trình **9 bước tuần tự**: *Khoảng cách (Spacing) → Màu sắc (Color) → Biểu tượng (Icons) → Nội dung chữ (Copy) → Kiểu chữ (Typography) → Bố cục (Layout) → Chi tiết phay viền (Details) → Đồ họa hình ảnh (Visuals) → Chuyển động lò xo (Motion)*.

### 3. Tẩy Rửa Dấu Vết & Watermark AI (`watermarks-remover`)
```bash
# Trong Terminal
npx skill-for-ai watermarks-remover <tệp-tin|thư-mục> [--fix]

# Trong AI Chat
/watermarks-remover [tệp tin | thư mục]
```
Làm sạch các ký tự tàng hình (`\u200B`, `\u200C`, `\u200D`), mã biến thể ẩn (`\uFE00`–`\uFE0F`), comment phát sinh của AI và siêu dữ liệu tài liệu.

### 4. Kiểm Định Chuẩn Web Hiện Đại Google Chrome (`modern-web-guidance`)
```bash
# Trong Terminal
npx skill-for-ai modern-web-guidance <tệp-tin|thư-mục>

# Trong AI Chat
/modern-web-guidance [tệp tin | thư mục]
```
Kiểm tra và nâng cấp giao diện theo quy chuẩn Chrome DevRel (Container Queries, Anchor Positioning, native `<dialog>`, và Core Web Vitals).

### 5. Quét Lỗ Hổng & Bản Vá Bảo Mật OpenAI Codex (`codex-security`)
```bash
# Trong Terminal
npx skill-for-ai codex-security <tệp-tin|thư-mục>

# Trong AI Chat
/codex-security [tệp tin | thư mục]
```
Rà quét khóa bí mật bị lộ, nguy cơ injection và tự động tạo bản vá phẫu thuật an toàn với bán kính tác động tối thiểu.

### 6. Trung Tâm Cộng Tác Đa Agent Tự Host (`agentes-chat`)
```bash
# Trong Terminal
npx skill-for-ai agentes-chat [init|start|status]

# Trong AI Chat
/agentes-chat [init|start|status]
```
Khởi tạo và chạy trung tâm chat cộng tác đa Agent qua Docker Compose với bus công cụ MCP tích hợp sẵn.

## 💎 Hệ Sinh Thái Web Hiện Đại, Thiết Kế & Bảo Mật

* **`unslop`** (`heydamir/unslop`): Triệt tiêu phong cách AI Slop (xóa viền neon tím, nhãn emoji tùy tiện, sáo ngữ quảng cáo rỗng tuếch) qua 9 bước kiểm định thiết kế khắt khe.
* **`modern-web-guidance`** (`googlechrome/modern-web-guidance`): Quy chuẩn nền tảng Web hiện đại chính thức từ đội ngũ Google Chrome: CSS Container Queries (`@container`), CSS Anchor Positioning, Popover API, `<dialog>`, View Transitions API, tối ưu Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1).
* **`codex-security`** (`openai/codex-security`): Bộ công cụ kiểm toán mã nguồn từ OpenAI, tự động tạo bản vá lỗ hổng (patch) với phạm vi ảnh hưởng tối thiểu, kiểm tra chống rò rỉ secret key.
* **`watermarks-remover`** (`guillaumemeyer/watermarks-remover`): Kiểm tra và loại bỏ các loại watermark AI ẩn, ký tự Unicode biến thể (variation selectors), khoảng trắng ẩn (zero-width spaces) và metadata định danh trên tài liệu/hình ảnh bạn sở hữu.
* **`agentes-chat`** (`agentes-chat/agentes-chat`): Nền tảng cộng tác nhóm tự lưu trữ (self-hosted) kết nối con người và các AI Agent (Claude, GPT, Gemini) trong các kênh thảo luận chung có gắn công cụ MCP.
* **`meta-astryx-design-system`** (`meta/astryx`): Hệ thống thiết kế của Meta với React 19, StyleX, cascade theming đổi giao diện không cần render lại, và MCP server tra cứu token chuẩn.

## 🎬 Bộ Công Nghệ Video Lập Trình, Toán Học & Giọng Đọc AI

* **`programmatic-video-remotion`**: Tạo video hoàn toàn bằng code React 19 qua Remotion, nhúng 3D Three.js (`@remotion/three`), vật lý lò xo (spring physics) chuẩn xác từng frame, xuất video MP4 tự động.
* **`math-animation-manim`**: Engine hoạt họa toán học của 3Blue1Brown: biến đổi mượt mà công thức LaTeX (`TransformMatchingTex`), vẽ đồ thị hàm số và không gian 3D.
* **`vietnamese-neural-tts`**: Tạo giọng đọc AI tiếng Việt tự nhiên chuẩn vùng miền (Bắc/Trung/Nam) bằng **VieNeu-TTS** và **ViFastTTS** (streaming thời gian thực), chuẩn hóa số/ký hiệu, tự động sinh phụ đề `.srt` khớp từng từ.
* **`media-pipeline-ffmpeg`**: Quy trình xử lý video/audio qua FFmpeg: tự động giảm nhạc nền khi có giọng đọc (`sidechaincompress` audio ducking), dập phụ đề cứng, tăng tốc phần cứng NVENC, cắt định dạng 16:9 sang 9:16 Shorts/Reels/TikTok.
* **`motion-graphics-hyperframes`**: HyperFrames, GSAP Timelines, và Three.js render canvas 60fps không phụ thuộc vào thời gian thực để xuất video đồ họa chuyển động sắc nét.

## 🎮 Bộ Vũ Khí Phát Triển Game (Game Development & Game Feel)

* **`game-development-godot`**: Chuẩn Godot 4.3+ GDScript, Static Typing bắt buộc, tách biệt Node ("Call Down, Signal Up"), cấu trúc dữ liệu Resource (`.tres`), và kiểm thử ngầm (`godot --headless --quit`).
* **`game-development-unity`**: Chuẩn Unity C#, tối ưu hiệu năng không sinh rác bộ nhớ (Zero-GC Object Pooling `UnityEngine.Pool`), kênh sự kiện ScriptableObjects, và New Input System.
* **`game-design-and-feel`**: Thiết kế Core Loop, viết GDD mẫu, công thức cân bằng game, và 5 chuẩn Game Feel ("Juice"): Rung màn hình, Dừng khung hình (Hitstop 60ms), Kéo dãn (Squash & Stretch), Coyote Time (120ms) & Bộ đệm nhảy (Jump Buffering 100ms).
* **`game-assets-and-audio`**: Danh bạ tài nguyên miễn phí 100% bản quyền thương mại (Kenney.nl, Quaternius Low-poly 3D, Adobe Mixamo, Poly Haven, AmbientCG, Freesound, Sonniss GDC).
* **`game-engine-mcp-integration`**: Cấp "tay chân" cho AI trực tiếp điều khiển Game Engine (Godot MCP, Unity MCP, Blender MCP, Aseprite MCP).
