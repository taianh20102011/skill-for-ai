## 🚀 1-Click Install & Multi-Agent Mesh Linking

Run a single command in your terminal:

```bash
npx skill-for-ai
```
*(Or install non-interactively with auto-confirmation: `npx skill-for-ai -y`)*

This command automatically deploys and links **all 337+ Production Skills** across your agent runtimes:
* 🔹 **Google Antigravity / Gemini CLI**: `~/.gemini/config/skills`
* 🔹 **Claude Code**: `~/.claude/skills`
* 🔹 **OpenCode / Codex Agents**: `~/.agents/skills`
* 🔹 **Cursor / VS Code**: Generates project-level `AGENTS.md` and `.cursorrules` in your current working directory.

### 2. UI De-Slopping Engine (`/unslop`)
Audit and refine AI-generated user interfaces into intentional, human-crafted designs:

```bash
# In Terminal
npx skill-for-ai unslop <file|dir> [--fix]
# or
unslop <file|dir> [--fix]

# In AI Chat
/unslop [file | URL | component]
```
Executes **9 sequential review passes**: *Spacing → Color → Icons → Copy → Typography → Layout → Details → Visuals → Motion*.

### 3. AI Provenance & Watermark Sanitizer (`watermarks-remover`)

Strips zero-width spaces (`\u200B`, `\u200C`, `\u200D`), variation selectors (`\uFE00`–`\uFE0F`), AI comments, and document metadata.
