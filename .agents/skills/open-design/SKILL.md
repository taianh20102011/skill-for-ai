# Open Design (Local-First AI Design Agent Workspace)

Based on [nexu-io/open-design](https://github.com/nexu-io/open-design).

## 1. What Open Design Does

* **Local-First Canvas**: Runs directly on your device with no cloud lock-in.
* **Bring-Your-Own-Key (BYOK)**: Supports OpenAI, Anthropic, Gemini, DeepSeek, or local Ollama instances.
* **Sandboxed Iframe Previews**: Code changes are immediately rendered and previewed in an isolated sandbox with zero page reload.
* **Design Systems & Tokens**: Standardized color scales, typography tokens, and spacing grids.
* **Seamless Code Export**: Generates production-ready React (JSX/TSX) + Tailwind CSS components.

---

## 2. Design Workflow

1. **Brief Specification**: State high-level requirements (e.g., "A modern fintech analytics dashboard with transaction stream and spending breakdown").
2. **Token Definition**: Establish color palette (Canvas `#F7F8FA`, Card `#FFFFFF`, Ink `#0F172A`, Accent Sapphire `#2563EB`) and radius (`6px`).
3. **Component Iteration**: Agent generates modular sections into preview sandbox.
4. **Export & Refine**: Export code to project repository and integrate with Radix/Animate UI/GSAP.
