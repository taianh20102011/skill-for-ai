# Modern Desktop Tools & App Development Skill

This skill provides patterns for building high-performance, instant-startup desktop tools and native applications.

## 1. Core Frameworks
- **Tauri v2**:
  - Core written in Rust for minimal memory footprint (<15MB RAM) and tiny bundle sizes (<10MB).
  - Frontend powered by Vite + React + TypeScript + Tailwind CSS.
  - Safe IPC communication using Tauri `invoke` and event listeners.
- **Electron-Vite**:
  - Modern Electron template pre-configured with Vite, React, and TypeScript.
  - Fast Hot Module Replacement (HMR) and optimized multi-window setups.

## 2. Desktop UI Patterns
- **Linear/VS Code Style**: Collapsible sidebars, tabbed navigation, status bar.
- **Command Palette (`cmdk`)**: Quick keyboard-driven navigation (`Ctrl + K`).
- **Dark Neutral Palette**: `#0a0c10` with subtle border separations (`border-white/10`).
