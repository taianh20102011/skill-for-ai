## 🚀 一键安装与多智能体网络互联

在终端中只需执行单条命令：

```bash
npx skill-for-ai
```
*(或直接通过 GitHub 运行：`npx github:taianh20102011/skill-for-ai`)*

该命令将自动将 **90+ 生产级核心技能** 注入到您的智能体运行环境中：
* 🔹 **Google Antigravity / Gemini CLI**: `~/.gemini/config/skills`
* 🔹 **Claude Code**: `~/.claude/skills`
* 🔹 **OpenCode / Codex Agents**: `~/.agents/skills`
* 🔹 **Cursor / VS Code**: 自动在当前项目根目录下生成 `AGENTS.md` 和 `.cursorrules`。

---

### 🤖 交互式权限确认与模式选择
在运行安装脚本时，CLI 将主动提示确认：
1. **确认多智能体网格连接**：
   ```text
   ? 是否允许自动将所有 AI Agent 互联为一个统一协作系统？ (Y/n)
   ```
2. **选择运行模式 (Operating Mode)**：
   * 🌟 **Senior Dev Mode (高级架构师模式 - 推荐)**：
     * 践行 **YAGNI (Ponytail)** 哲学：编写解决问题的最精简代码，彻底消除死代码与冗余抽象。
     * 自主编译器闭环 (`pnpm build`、`./gradlew build`、`cargo check`)，报错时自动捕获堆栈并自愈修复代码。
     * 自动遵循 Cloudflare 安全准则与 OWASP Top 10 进行安全审计。
   * 🎓 **Junior Dev Mode (导师辅导模式)**：
     * 辅导教学模式：分步引导，详细解释每个函数和变量的业务逻辑。
     * 在代码中添加详尽注释，便于学习与理解。

## 🛠️ 自主超级构建命令: `/xaydung`

安装完成后，直接在 **Antigravity / Claude Code / Cursor** 的对话框中输入命令：

```text
/xaydung web <网页需求或设计构想>
/xaydung app <桌面端或移动端应用描述>
/xaydung plugin <Minecraft Paper/Purpur 插件功能>
/xaydung tool <CLI 实用工具或自动化脚本>
```

### 自主后台执行管线：
1. **架构分析与头脑风暴**：生成详细的技术规格与任务拆解。
2. **脚手架初始化**：智能匹配现代技术栈 (React/Tailwind/GSAP/Lenis, Tauri v2 / Rust, 或 Paper Adventure)。
3. **自主编码实现**：严格依据选定的模式（高级或初级）编写规范代码。
4. **编译自愈闭环 (Compiler Loop)**：执行构建与测试命令，自动解析错误日志并修复 Bug。
5. **安全与质量审计**：依据 Cloudflare 规范、OWASP Top 10 及 Semgrep SAST 执行静态代码审计。

## 📦 技能库总览 (90+ 精选技能)

### 1. 极致 Web UI 与微交互 (Zero Slop - 反粗制滥造)
* **`anti-slop-web-ui`**：高端视觉审美规范：深色调 `#080808`，Geist / JetBrains Mono 字体排印，150-250ms 弹簧微物理效果。
* **`react-bits`**：动画组件库：*SplitText, DecryptedText, Iridescence, Aurora, Particles, SpotlightCard*。
* **`animate-ui`**：苹果/Linear 级微交互：平滑模态变形、弹性选项卡、手势物理反馈。
* **`cinematic-3d-web`**：R3F、Drei、Three.js 画布，针对 60 FPS 优化的自定义 GLSL 着色器。
* **`gsap-scroll-mastery`**：GSAP ScrollTrigger 与 Lenis 平滑滚动深度同步。
* **`vercel-react-performance`**：Core Web Vitals 性能极限优化 (LCP < 2s, INP < 150ms, CLS < 0.05)。

### 2. 网页与移动端自主智能体 (Web & Mobile Agents)
* **`browser-use-agent`**：基于 Playwright 的自主网页导航、表单填写与 DOM 提取智能体。
* **`mobile-app-automation-agent`**：移动端 UI 自动化操控与测试 (Android UIAutomator2, iOS XCUITest, Appium, LaVague LAM)。

### 3. Minecraft 纯净架构与 AI 沙盒
* **13 项 Minecraft 专项技能**：`minecraft-plugin-dev`, `minecraft-modding`, `minecraft-commands-scripting`, `minecraft-datapack`, `minecraft-server-admin`, `minecraft-worldedit-ops` 等。
* **AI 沙盒集成**：连接 `AgentCraft`（AI 编程虚拟办公室）与 `MindCraft`（Mineflayer 智能机器人）。

### 4. 企业级网络安全与蓝队纵深防御
* **`cloudflare-security-audit`**：Cloudflare 官方全维度安全审计规范。
* **`owasp-top-10-audit` & `owasp-security-cheatsheets`**：OWASP Top 10 漏洞审计与主动防御检查清单。
* **`siem-detection-and-blue-team`**：Sigma YAML 威胁检测规则编写与 Active Directory 加固。
* **`secret-leak-detection`**：提交前敏感信息（OpenAI、AWS、GitHub 密钥）泄漏拦截。
* **`reverse-engineer-anything` (REA)**：二进制逆向工程，APK、Electron 及 WebAssembly 代码审计。

### 5. 自主开发闭环与工程师效率工具
* **`superpowers`**：头脑风暴、详细计划制定 (`writing-plans`)、子智能体驱动开发、测试驱动开发 (TDD) 及完成前终验。
* **`ponytail`**：务实资深架构师模式（YAGNI、代码瘦身、技术债务记账）。
* **`agent-skills-addy`**：Google Chrome 团队技术负责人 (Addy Osmani) 的 Web 工程最佳实践。
